# Glossário de mercado financeiro

## Indicadores e múltiplos

| Termo | Significado |
|---|---|
| **CAGR** | Taxa composta de crescimento anual. `(Valor final / Valor inicial)^(1/n) − 1` |
| **DY** | Dividend Yield. Proventos dos últimos 12 meses ÷ preço |
| **EBIT** | Lucro antes de juros e impostos. Resultado operacional |
| **EBITDA** | EBIT + depreciação + amortização. Proxy de geração de caixa operacional |
| **EV** | Enterprise Value. Valor de mercado + dívida líquida |
| **FCL / FCF** | Fluxo de caixa livre. Caixa operacional − capex |
| **LPA** | Lucro por ação. Lucro líquido ÷ número de ações |
| **NOPAT** | Lucro operacional depois de impostos. `EBIT × (1 − alíquota)` |
| **P/L** | Preço ÷ lucro por ação |
| **P/VP** | Preço ÷ valor patrimonial por ação |
| **PEG** | P/L ÷ crescimento esperado do lucro |
| **PSR** | Preço ÷ receita por ação |
| **Payout** | Fração do lucro distribuída como proventos |
| **ROA** | Retorno sobre o ativo total |
| **ROE** | Retorno sobre o patrimônio líquido |
| **ROI** | Retorno sobre o investimento |
| **ROIC** | Retorno sobre o capital investido (próprio + terceiros) |
| **VPA** | Valor patrimonial por ação. PL ÷ número de ações |
| **WACC** | Custo médio ponderado de capital |

## Risco

| Termo | Significado |
|---|---|
| **Beta (β)** | Sensibilidade do ativo ao índice de mercado |
| **Correlação** | Grau em que dois ativos se movem juntos (−1 a +1) |
| **Drawdown** | Queda do pico ao fundo antes de novo pico |
| **Sharpe** | Retorno excedente ÷ volatilidade |
| **Sortino** | Retorno excedente ÷ volatilidade das quedas |
| **Suitability** | Adequação do investimento ao perfil do investidor |
| **VaR** | Value at Risk. Perda máxima esperada num horizonte e nível de confiança |
| **Volatilidade** | Desvio padrão dos retornos |

## Demonstrações e contabilidade

| Termo | Significado |
|---|---|
| **Ágio** | Valor pago acima do patrimônio numa aquisição |
| **Balanço Patrimonial** | Foto de ativo, passivo e patrimônio em uma data |
| **Capex** | Investimento em ativo imobilizado |
| **Capital de giro** | Ativo circulante − passivo circulante |
| **CPV / CMV** | Custo dos produtos / mercadorias vendidos |
| **DFC** | Demonstração dos fluxos de caixa |
| **DRE** | Demonstração do resultado do exercício |
| **Impairment** | Baixa contábil de um ativo que perdeu valor |
| **Opex** | Despesa operacional recorrente |
| **PL** | Patrimônio líquido. Ativo − passivo |
| **Provisão** | Reserva contábil para obrigação provável |

## Mercado e negociação

| Termo | Significado |
|---|---|
| **After-market** | Sessão de negociação após o pregão regular |
| **Book / Livro de ofertas** | Lista de ordens de compra e venda abertas |
| **Circuit breaker** | Interrupção automática do pregão em queda brusca |
| **Custódia** | Guarda dos ativos, feita pela B3 via corretora |
| **Free float** | Fração das ações em circulação no mercado |
| **Gap** | Salto de preço entre o fechamento e a abertura seguinte |
| **Home broker** | Plataforma de envio de ordens da corretora |
| **Leilão** | Fase de formação de preço na abertura e no fechamento |
| **Liquidez** | Facilidade de comprar/vender sem mover o preço |
| **Lote padrão** | 100 ações. O fracionário negocia de 1 a 99 (ticker com `F`) |
| **Market maker** | Agente contratado para dar liquidez a um ativo |
| **Spread** | Diferença entre a melhor oferta de compra e de venda |
| **Volume financeiro** | Total negociado em reais no período |

## Proventos e eventos societários

| Termo | Significado |
|---|---|
| **Bonificação** | Distribuição de novas ações aos acionistas, sem custo |
| **Data com** | Último pregão com direito ao provento |
| **Data ex** | Primeiro pregão sem direito ao provento |
| **Desdobramento (split)** | Divisão da ação em mais unidades, reduzindo o preço unitário |
| **Dividendo** | Distribuição de lucro aos acionistas |
| **Grupamento (inplit)** | Junção de ações, elevando o preço unitário |
| **JCP** | Juros sobre capital próprio. Remuneração dedutível para a empresa, tributada em 17,5% na fonte desde 2026 |
| **Recompra** | Empresa comprando as próprias ações |
| **Subscrição** | Direito de comprar novas ações emitidas, geralmente com desconto |
| **Tag along** | Percentual do valor pago ao controlador garantido ao minoritário numa venda de controle |

## Órgãos e estruturas

| Termo | Significado |
|---|---|
| **ANBIMA** | Associação que autorregula o mercado de capitais |
| **B3** | Bolsa brasileira (Brasil, Bolsa, Balcão) |
| **BACEN** | Banco Central do Brasil |
| **CMN** | Conselho Monetário Nacional |
| **Copom** | Comitê de Política Monetária. Define a Selic |
| **CVM** | Comissão de Valores Mobiliários. Regula o mercado de capitais |
| **Novo Mercado** | Segmento de listagem da B3 com as maiores exigências de governança: só ações ON, 100% de tag along, free float mínimo |
| **Nível 1 / Nível 2** | Segmentos intermediários de governança |

## Macroeconomia

| Termo | Significado |
|---|---|
| **CDI** | Certificado de Depósito Interbancário. Benchmark da renda fixa; roda colado na Selic |
| **Deflação** | Queda generalizada de preços |
| **IGP-M** | Índice Geral de Preços do Mercado. Usado em contratos de aluguel |
| **IPCA** | Índice oficial de inflação, medido pelo IBGE |
| **PIB** | Produto Interno Bruto |
| **Selic** | Taxa básica de juros da economia |
| **TJLP / TLP** | Taxa de juros de longo prazo, usada em financiamentos do BNDES e no cálculo do limite de JCP |

## Renda fixa

| Termo | Significado |
|---|---|
| **CDB** | Certificado de Depósito Bancário. Coberto pelo FGC |
| **CRI / CRA** | Certificado de recebíveis imobiliários / do agronegócio. Isento de IR para PF, sem FGC |
| **Debênture** | Dívida emitida por empresa. Incentivada é isenta de IR para PF |
| **FGC** | Fundo Garantidor de Créditos. Garante até R$ 250 mil por CPF por instituição, com teto de R$ 1 milhão a cada 4 anos |
| **LCI / LCA** | Letra de crédito imobiliário / do agronegócio. Isenta de IR para PF, coberta pelo FGC |
| **Marcação a mercado** | Atualização diária do preço do título conforme a taxa vigente |
| **Prefixado** | Taxa conhecida na compra |
| **Pós-fixado** | Atrelado a um indexador (CDI, Selic) |
| **Híbrido** | Indexador + taxa fixa (ex.: IPCA + 6%) |
| **Tesouro Direto** | Programa de venda de títulos públicos federais a pessoa física |

## Fundos e veículos

| Termo | Significado |
|---|---|
| **BDR** | Recibo na B3 que representa ação estrangeira |
| **Cap rate** | Receita anual de aluguel ÷ valor do imóvel |
| **Come-cotas** | Antecipação semestral de IR em alguns fundos (não se aplica a FIIs nem a fundos de ações) |
| **ETF** | Fundo de índice negociado em bolsa |
| **FII** | Fundo de Investimento Imobiliário |
| **Taxa de administração** | Custo anual do fundo, já descontado da cota |
| **Taxa de performance** | Cobrada sobre o que exceder o benchmark |
| **Vacância** | Fração dos imóveis de um FII sem locatário |
